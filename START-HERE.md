# Start here

Your IELTS coaching center. The teacher is **Anita Miss**.

## Set up (one time)

1. Unzip this folder somewhere easy, for example `C:\Users\<you>\ielts-coaching`.
   Keep the `.claude` folder inside it (Windows may hide folders that start with a dot; that's fine).
2. You need **Claude Code** installed and signed in (Claude Pro or Max plan). If the installer asks for
   **Git for Windows**, install it too.
3. Open Claude Code **in this folder**. In a terminal:
   ```
   cd C:\Users\<you>\ielts-coaching
   claude
   ```
4. The first time, Claude Code asks if you trust this folder and later asks permission to run the timer
   and read-aloud tools. Choose **Yes** (or "don't ask again").

## Every day

| Type | What it does |
|---|---|
| `/placement` | Day 1 placement test (the teacher starts it automatically the first time) |
| `/class` | Start or continue today's class |
| `/writing task2` | Timed essay + strict examiner score |
| `/dictation` | Listen and type practice |
| `/mock Cambridge 18 Test 1` | Full mock test with your Cambridge book |
| `/speaking` | After phone voice practice: paste the examiner's feedback |
| `/report` | Weekly report card (the teacher also makes it automatically every 7 days) |
| `/progress` | Chart of your scores and study hours |
| `/pause` | Leave class; the teacher saves where you stopped |

Or just type normally, like "Good morning Miss".

## Also needed

- **Cambridge IELTS Academic books** as PDFs in the `books` folder (see `books/README.md`), with their
  Listening audio. Free official practice tests: British Council (takeielts.britishcouncil.org) and IDP
  (ielts.idp.com).
- **Phone:** 30 minutes a day of speaking in voice mode in the Claude app. Paste the prompt from
  `speaking/voice-examiner-prompt.md` first. Afterwards, run `/speaking` here and paste the feedback.
- **20 minutes a day of easy English** outside class: graded readers, learner news, BBC Learning English.
- **Before your real test:** one mock test checked by a human examiner (official or paid), especially Speaking.
- **Speakers or headphones** for the timer beeps and dictation.

## Tips

- Start a new chat every day. The teacher remembers you through the files in `student/`, and a fresh chat
  follows the teacher's rules best.
- If something sounds wrong, ask "Are you sure? Show me the rule." Trust your book and official IELTS sites
  (British Council, IDP, ielts.org) over the AI.
- Reading and Listening scores (marked from the book's answer key) are the most reliable. Writing and Speaking
  scores are estimates and may be a bit high.
- Never let the teacher do your work for you. You learn by trying.
- Study hard, but sleep well. Tired study doesn't stick.
