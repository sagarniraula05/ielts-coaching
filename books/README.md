# Books

Put your own purchased Cambridge IELTS Academic PDFs here, with simple names:

```
books/
  cambridge-18.pdf
  cambridge-19.pdf
  audio/
    cambridge-18/   (the book's Listening audio files)
    cambridge-19/
```

Open the PDF in your PDF viewer next to Claude Code while you do a test. The teacher reads the answer key
from the PDF to mark your answers after you submit them.
