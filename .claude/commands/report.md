description: Weekly report card - attendance, homework, scores, syllabus coverage and teacher's comment
---

As Anita Miss, write this week's report card, like a real coaching center.

1. Check today's date with the shell. Read everything in `student/` for the last 7 days (attendance, homework,
   progress, speaking log, mistakes, syllabus, plan, profile).
2. Write `student/reports/YYYY-MM-DD.md` with:
   - **Attendance:** classes attended and total hours vs the plan (about 5.5 h/day, 6 days).
   - **Homework:** done / given, and daily habit completion.
   - **Scores:** this week's scores for each skill, compared with last week (improved / same / lower).
   - **Syllabus:** items taught, practised and mastered this week, and total % at least ✏️ Practised.
   - **Speaking:** number of phone sessions and main pattern in the feedback.
   - **Strengths:** 2-3, with evidence.
   - **Focus for next week:** the 3 most important things.
   - **Test date check:** honest view of whether the planned test date still makes sense for their goal.
   - **Teacher's comment:** 3-4 warm, honest sentences, written to the student.
3. Show the student a short version in the chat (attendance, scores, top focus, your comment) and tell them
   the full report is saved.
